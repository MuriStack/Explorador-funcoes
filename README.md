
# Explorador de Funções

Aplicação desenvolvida em Python para explorar, comparar e visualizar funções afins por meio de gráficos.

## Sobre o projeto

O Explorador de Funções permite definir duas funções afins, analisar suas relações matemáticas e visualizar seus gráficos em um plano cartesiano.

O projeto foi criado com o objetivo de praticar programação em Python e aplicar conceitos matemáticos por meio de uma representação visual.

## Demonstração

![Gráfico das funções afins](imagens/grafico.png)

## Funcionalidades

- Definição dos coeficientes de duas funções afins.
- Construção de gráficos para comparar as funções.
- Identificação do ponto de interseção, quando existente.
- Verificação de interseção dentro ou fora do intervalo definido.
- Identificação de funções paralelas ou coincidentes.
- Visualização do plano cartesiano com eixos e grade.

## Tecnologias utilizadas

- **Python** — lógica e processamento matemático.
- **Matplotlib** — construção e visualização dos gráficos.

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/MuriStack/Explorador-funcoes.git
cd Explorador-funcoes
```

### 2. Crie e ative um ambiente virtual

No Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Instale a dependência

```bash
pip install matplotlib
```

### 4. Execute o programa

```bash
python explorador.py
```

## Conceitos aplicados

- Funções afins: \(f(x) = ax + b\).
- Coeficientes angular e linear.
- Interseção entre retas.
- Estruturas de repetição.
- Funções em Python.
- Listas e visualização de dados.
